# SQLite 管理式笔记

2026-11-06。产品目标是随手记录、收集、聚合与找回。内部笔记由应用负责保存；Markdown 是正文与交换格式，不要求每篇内部笔记在磁盘上存在独立文件。

## 界面与入口

默认进入“我的笔记”，不再选择／切换磁盘笔记库。侧栏提供全部、随手记、收藏、最近删除、智能集合及可展开的文件夹树。普通文件夹只显示直接归属的笔记；全部笔记负责跨分类聚合。点击文件夹名称选择，前方箭头只控制展开。

“设置 → 数据”提供笔记导入、整夹收集、导入记录、导出与完整备份恢复；“设置 → 高级”提供临时编辑外部 Markdown。侧栏只展示笔记分类，空空间另提供导入引导。已有文件仓库通过“设置 → 数据 → 之前的笔记”明确创建副本；源文件、旧元数据、草稿和历史均不自动删除或搬移。恢复旧模式的独立草稿／历史需在旧仓库中另行取回，不自动当作正文导入。

导入预览显示笔记／目录数量，选择归属位置、保留层级和重复策略。默认保留层级、跳过来源路径和源摘要均相同的已导入笔记。重名生成不同虚拟路径，不覆盖原笔记；修改过的源文件再次导入生成副本，而非覆盖应用内编辑。预览后的源变化报告失败，之后新增文件不悄悄纳入已确认批次。

导入结果与记录包含成功／跳过／失败逐项结果，以及关联资源警告。点击记录查看该批次目前仍存在的笔记，详情可重看报告。导入是独立副本，不再监听源目录。

整目录保留空目录和层级。普通 Markdown 行内／引用式资源链接通过已有 URL 解析器处理：被导入的笔记指向管理空间内路径，本地附件收集到资产表。范围外／不存在的关联资源会警告，不自动读取未知位置。HTML 链接／图片不由这个解析器重写，正文保留并明确警告未自动收集。歧义双链不自动猜测；唯一相对路径可以映射，单纯名称仍受重名歧义限制。

外部文件具有明显标识；正文可编辑并保存回原文件，不进入内部分类、全局搜索、导入记录或未来 AI 索引。导入为笔记另走同一预览流程。保存仍校验文件摘要，外部已改／删除时不直接覆盖；当前编辑缓冲保留，可生成内部副本。

## 不变的约定

SQLite 是内部笔记、文件夹、标签、收藏、回收记录、导入记录与历史的权威来源；正文是 Markdown，但不以磁盘目录扫描决定内部笔记是否存在。重名不覆盖，重复导入按来源与内容摘要识别。失败、越界引用与格式不支持必须报告，不能静默丢内容。封闭管理只表示应用负责保存，不表示锁定用户数据：笔记、文件夹与全部内容都可导出 Markdown 与附件，导出不改变内部归属。保留旧文件仓库与原始文件，不自动删除、覆盖，也不把旧路径当作新数据库。

## 存储与身份

`src/storage/ManagedStore.cpp` 运行于既有 Repository 工作线程。SQLite 表包含 notes、folders、drafts、versions、assets、imports 和 settings。笔记与文件夹拥有独立稳定 ID；笔记路径是兼容现有编辑器的虚拟定位符，不是内部正文文件。移动／改名不更换笔记 ID。显示标题来自 Markdown 标题或 title 属性；重命名笔记更新标题，保存可回看版本。

数据库为应用数据目录下 `Library/notes.sqlite3`；显式 `--settings-dir` 会把内部空间隔离到指定设置目录下的 Library，避免演示偏好污染正常空间。WAL、FULL synchronous、外键和受控事务用于持久化；管理空间有单实例锁。

每次工作线程操作明确提交或回滚；批处理每项有 savepoint，导入报告记录部分失败。历史按身份保存最近 50 个不同内容版本。分类、收藏、回收状态和正文都由 SQLite 驱动，不扫描磁盘文件夹决定笔记是否存在。

资产 BLOB 为权威内容；`Library/assets/` 是供现有 Web 编辑器同窗口资源协议读取的可再生附件缓存，不保存独立 Markdown 原件。外部文件保持独立读取／摘要校验路径。旧文件存储代码暂留兼容参考，默认启动不再进入该模式。

## 搜索、聚合与导出

标题、正文、标签、属性、收藏和分类查询接入数据库内容；现阶段复用内存中文子串索引，每次查询增量比对数据库内容。智能集合保存查询条件；数据库不是 AI 或语义搜索的替代品。大规模 SQL 全文检索、后台分块和 AI 向量检索尚未实现。

全部、单篇和文件夹可导出 Markdown＋关联附件到用户所选位置内的新目录，避免覆盖已有文件；导出不删除／移动内部笔记。当前导出保留内部虚拟路径与层级（新建笔记文件名可能含短 ID）。单篇或部分导出不会自动补齐范围外链接笔记。

外部文件保存回原文件与导入是两种不同操作。导入不是双向同步。备份／跨设备同步仍需后续单独设计，不应直接把正在写入的 SQLite/WAL 当作普通 Markdown 同步。

## 本轮完成与边界

按本会话要求只编译并打开应用供用户查看，不运行测试、verify 或图形交互验证。编译不等于功能／持久化／迁移验收。旧数据保持原状，导入须由用户在界面确认。
