# 以笔记为中心的界面入口

2026-11-06。主界面服务于记录、查找和整理；磁盘文件只作为收集来源、临时编辑对象或输出位置出现。

## 日常界面

- 顶部左侧放新建，中间公共按钮组提供配套的撤销／重做、段落样式、粗体／斜体／删除线、行内代码，以及独立的引用、代码块、链接和任务清单。列表菜单只放列表与缩进；插入菜单放图片／附件、公式、脚注、目录和分隔线；表格保留全部行列操作。唯一正文“更多”位于按钮组末尾，按钮组支持横向滚动和键盘焦点显露；右侧搜索默认收起为图标按钮，点击或按搜索快捷键后展开输入框；宽窗口不自动展开。顶部液态按钮统一使用中档强度，按钮组竖线高 12px、在主题边框原有透明度上再乘 0.65，正文区域最小宽 720px；缩小窗口时正文不再继续变窄：先收起左侧导航，再收起笔记列表，最后只剩正文单栏，窗口最小宽度即正文最小宽度。侧栏隐藏时（列表＋正文或仅正文）不再显示“笔记”标题和“全部／收藏／最近删除”分类按钮，顶部只保留侧栏按钮；列表＋正文时点击该按钮展开侧栏并由列表让出位置，再点一次返回列表。拖动浏览栏分隔条同样不会把正文压到该宽度以下，设置放在左侧栏底部，使用普通导航按钮。
- 侧栏分为“视图”和“文件夹”：视图包含全部笔记、收藏、最近删除及已保存的搜索筛选；文件夹包含“随手记”、初始化时添加的“默认文件夹”和用户创建的顶层文件夹；子文件夹放在对应笔记列表上方，通过返回上一级逐层导航。侧栏底部不显示新建文件夹，暂不增加“新建视图”入口；保存搜索仍从设置进入。
- “随手记”和“默认文件夹”都是仅初始化一次的普通文件夹，支持重命名、移动、删除和恢复，之后不自动补回。升级时将原收件箱的正常笔记一次性归入“随手记”，保留笔记 ID 并调整路径链接；有待恢复草稿或无法调整的链接时，整批保留原位并提示。在具体文件夹中新建归入当前文件夹；新建或导入未指定文件夹时显示为“未分类”，可在“全部笔记”中找到，不会隐式重建“随手记”。
- 正文左右各保留 48px 留白，笔记名称与正文左对齐；块操作按钮放在左侧留白内，与正文相隔 8px，并至少离开编辑区边界 12px。
- 正文上方提供独立的“笔记名称”输入框，按 Enter 或“保存名称”提交；新建笔记的名称默认为“未命名笔记”，正文为空。名称保存在 Markdown 元数据的 `title` 字段中，修改名称不改写正文标题，也不将名称列入正文大纲。正文标题仍通过格式工具或 Markdown 设置。
- 唯一“更多”合并当前笔记和编辑工具：改名、信息、分享与导出、源码／正文切换、大纲、图片属性、代码语言与复制、附件管理。置顶、收藏、移动、副本和删除保留在列表／画廊右键菜单。分享与导出仍提供 PDF、Markdown、HTML 和打印；外部文件额外显示保存与导入。
- 列表右键菜单沿用邮件列表的定位：在鼠标点击位置弹出无箭头 LiquidPopover，只在接近窗口边缘时收进可见区域。笔记、子文件夹及最近删除列表使用同一规则；键盘打开笔记行菜单时以当前行中点作为位置，工具栏按钮仍就近弹出。
- 全部菜单与浮动表单采用统一触发规则：右键无箭头，按钮下方居中并指向按钮，后续菜单继承最初入口；空间不足时向上调整。完整范围和检查边界见 [菜单与浮动表单](popover-interactions.md)。
- 标签、关联和历史是当前笔记的信息，保留在“笔记信息”；模板管理从这套标签页中移出。
- 正文插入／表格／图片／公式等操作保留在编辑现场。编辑工具菜单不再夹杂整库管理和应用设置；当前笔记的输出在笔记菜单，不混入全局设置。
- 文件夹标题显示分类名称，不将完整分类路径当作页面标题。选择移动／导入目标时仍保留层级以区分同名分类。
- 空笔记空间提供次级“导入已有笔记”引导；普通使用时导入从设置进入。启动文案不再叫“打开我的笔记”。

## 列表与画廊

浏览栏上方的“更多”菜单提供“列表视图”和“画廊视图”，显示当前选项。全部笔记和各个文件夹分别记住偏好；文件夹中的子文件夹同步以列表或卡片呈现，保持键盘导航、多选、右键与拖放。列表保留时间分组；画廊为紧凑文字卡片，显示标题、最多两行摘要、一行日期及置顶／收藏状态。卡片高度 104px，行列间距 12px，默认浏览栏宽 448px，至少保持两列。两种视图共用笔记模型、排序、多选、右键和拖放归类，切换保留游标与选择。画廊宽度独立保存，回收站仍用列表。方向键移动游标，画廊上下键跨行，Enter 打开。

## 设置

设置位于左侧栏底部，使用普通导航按钮，快捷键 Ctrl+,；采用公共 LiquidDialog、LiquidSegmentedControl、SettingsGroup、SettingsItem 和既有控件，无独立自绘弹窗背景。

| 分区 | 内容 |
| --- | --- |
| 通用 | 阅读主题、正文字号、减少透明／动画、自动保存说明、快捷键 |
| 笔记管理 | 模板、保存搜索为智能视图、批量标签重命名、恢复草稿 |
| 数据 | 笔记导入、整夹收集、导入记录、旧笔记迁移；全部笔记导出；完整备份恢复；临时编辑外部 Markdown |

三个页签保持相同高度，按窗口可用空间缩小。选择管理操作后等待设置关闭动画完成，再打开相应表单；不在设置上层连续堆叠操作窗口。设置正文可滚动，底部完成按钮固定，键盘聚焦到下方控件时跟随滚动。

保留 Ctrl+O 的外部 Markdown 快捷操作；新增 Ctrl+Shift+I 导入。外部文件不加入聚合，只在明确导入后纳管；其身份和保存动作仅在实际打开外部文件时出现。

本轮只调整入口和呈现，不更换 SQLite 存储，不做 AI 索引。

本轮产品复查进一步修正搜索范围、标题／文件名区分、关联信息及临时编辑返回，见 [产品交互复查](product-interaction-review.md)。设置不是所有低频命令的堆放处：当前内容的输出就近放置，整库管理留在设置。

导出成功后保持在笔记应用中；只有用户主动选择“查看导出内容”才打开输出目录。临时编辑外部 Markdown 的身份栏提供明确结束入口。普通分类切换先保存当前输入，不让不属于目标分类的旧笔记残留在编辑区。

文件夹保留嵌套，作为应用内分类；侧栏底部不放置创建按钮，子文件夹创建放在具体行的菜单中。创建表单明确归属，创建后进入新分类，详见 [文件夹与嵌套交互](folder-interactions.md)。

后续交互统一按 [macOS 备忘录参照与适配](macos-interaction-reference.md) 执行，保留现有 Markdown、收藏、备份和公共组件能力；拖放归类与统一撤销见 [实现及边界](drag-undo.md)。
