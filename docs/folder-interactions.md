# 文件夹与嵌套交互

2026-11-06。保留“文件夹”和“子文件夹”的称呼，用来整理应用内笔记。它们不是磁盘目录的镜像；“全部笔记”仍聚合所有分类中的正常笔记。

- 导航只展示顶层文件夹，不显示树形缩进和展开箭头。进入文件夹后，直接子文件夹排在笔记列表上方；列表顶部提供返回上一级和当前文件夹操作。进入子级时侧栏仍高亮所属顶层文件夹。
- 宽窗口：侧栏标题“文件夹”只作为分组标题；移除标题旁的孤立加号和泛指当前目标的操作按钮。
- 创建顶层文件夹：侧栏底部固定显示“＋ 新建文件夹”。无论当前选中了什么，它都在“我的笔记”下创建，表单明确显示位置。
- 创建子文件夹：对具体文件夹打开行内菜单，选择“新建子文件夹”。表单显示父文件夹的名称和层级。
- 行内菜单：悬停／键盘聚焦的文件夹显示自己的操作入口；右键和 Shift+F10 同样针对这一行，不再让分组标题替某个不明确的文件夹执行操作。
- 窄窗口：在“文件夹”导航面板同样只展示顶层文件夹，底部保留“新建文件夹”；所选文件夹操作明确写出它的名称，右键／键盘菜单也可作用于具体文件夹。
- 新建只输入名称，不打开磁盘位置选择器。位置使用“我的笔记”或“父级 › 子级”，不显示绝对路径。
- 创建成功后直接进入新文件夹并将笔记列表滚动到顶部。此时可直接新建笔记，自动归入该文件夹。
- 同一位置的重名会在表单中提示并禁止重复创建；移动仍通过应用内的文件夹层级选择完成。

本轮只在 VM 隔离空间人工检查，不运行测试套件。本机仅按要求编译和打开供用户查看。

拖放悬停文件夹可进入下一层，子文件夹行也支持归类及行内菜单。移动目标选择器继续显示完整路径和全部层级。本次导航调整按用户要求仅编译并在本机打开，尚未进行 VM 交互验收。
