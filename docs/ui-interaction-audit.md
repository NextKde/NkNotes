# 交互与 UI 逐项审查

日期：2026-11-06。范围：当前管理式笔记迁移后的 QML 与界面。按用户要求不运行测试套件；运行时操作、截图只在 kos-vm-dev 的隔离演示空间进行。本机仅编译、打开供用户查看，不做图形验证。

## 统一规则

- 短操作列表使用公共 LiquidPopover；上下文表单使用 LiquidContentPopover；独立确认／导入／记录／信息使用 LiquidDialog。
- 文件、目录、附件和导出位置统一使用公共 LiquidFilePicker，避免默认文件选择框与应用风格明显不同。
- 对话框背景、圆角、阴影、标题、页脚由公共库管理，应用不替换背景。正文控件为实心普通材质。
- 标准页脚使用明确的中文动作；没有有效输入时不能确认。长正文滚动，按钮保持可见。
- 普通输入和多行输入复用 LiquidTextField、KosTextArea；选择项复用 LiquidSelect、LiquidCheckBox。保持键盘焦点及辅助功能。
- 空间、分类和外部文件身份清楚；不把虚拟路径、数据库字段或磁盘事务术语当作普通操作说明。

## 本轮发现并修正

1. 默认文件选择框与应用外观明显不一致：新增公共 LiquidFilePicker，覆盖全部六处文件／文件夹／附件／PDF／HTML 选择入口，支持多选、路径、键盘及覆盖确认。
2. 公共对话框未默认居中：定位与客户区限幅移到 LiquidDialog。
3. 导入确认按钮位于正文中，短窗口有裁切风险：改为标准尺寸页脚，正文可滚动，忙碌时不能 Escape 关闭。
4. 标准确认按钮使用通用 OK 或正文另放一套动作：公共组件支持动作文案和启用条件，标签、新建链接、删除、恢复等接入。
5. 实心输入框仍用了透明白色：在公共 LiquidTextField 修正材质分支，避免输入区域不可辨认。
6. 多行输入框仍为默认样式：接入公共 KosTextArea；长选项在公共 LiquidCheckBox 支持换行。
7. 笔记信息太大、标签页像四个普通动作按钮：用公共分段控件；普通标签优先展示，其他属性按需展开。历史对照窄窗口纵向排列。
8. 导入记录详情与标题可能重叠：预留详情按钮区域，统一按钮样式；时间改为简短本地格式。
9. 回收列表显示内部文件名：优先显示笔记标题，详情显示归属和删除时间。
10. 取消导入仍显示“正在读取”：预览／取消各有明确状态，取消清理计划。
11. 全成功导入也要求再关闭一个大结果框：成功直接返回列表，仅重复、失败、资源警告展开结果；全部报告可从导入记录重看。
12. 窄窗口列表标题与工具栏重叠：紧凑模式标题合并，列表操作及取消选择移到分类行。
13. 外观面板 implicitHeight 循环：给其明确、受窗口限制的高度。
14. 无当前笔记仍显示空正文统计、恢复中心显示空的底层事务解释、外部文件提供不支持的附件管理入口：移除或按身份禁用。
15. 外部文件发起导入后切换目标可能未更新计划：从确认计划同步来源及目标；单文件不展示目录结构选项。
16. 标签筛选在窄窗口未返回列表：统一触发列表展示。
17. 标准按钮采用 Linux 默认顺序：公共 DialogButtonBox 使用 MacLayout，取消在左、主操作在右；最终确认框已在 VM 回看。

修正补充：文件夹非法名称与原位置移动禁用；子文件夹表单支持 Enter 提交；公共文件选择器选择后获得列表键盘焦点；大批量列表成员变化用一次模型重置，减少中间布局；备份、导入和导出失败使用单独公共错误对话框；新建／复制／从模板新建会显示新笔记所在的结果。

## 以笔记为中心的入口重排（2026-11-06）

日常操作与设置重新分层，见 [界面入口说明](notes-interaction-model.md)。移除侧栏导入导出工具按钮；笔记菜单为置顶、收藏、移动、重命名、信息、副本、删除七项。导出与打印从正文工具移到设置“数据”，模板从笔记信息分段移到设置“高级”。

VM 人工操作覆盖：空空间引导打开两项收集菜单、新建笔记后查看七项笔记菜单；设置三分区切换，从设置进入导入并取消，从高级进入模板；540×480 窄窗口确认滚动正文和固定完成按钮。使用共享设置分组、行、选择器和对话框，未增加自绘弹窗背景。字号改用有明确数值和键盘操作的公共选择器；选择器的主题绑定跟随应用主题。

本轮不运行测试套件，未在本机做图形检查；没有重跑所有存储或导出组合。历史记录中的旧菜单路径已由当前入口说明取代。

最终构建在 VM 选择 20 磅，编辑器字号随之变化；数据分区可进入完整备份选择器后取消。截图覆盖最终通用页、数据分区、窄窗口和空空间引导；该轮截图已清理，未保留在仓库内。

入口重排的最终日志复查发现恢复确认框存在高度绑定循环，已改为明确受窗口限制的高度及可滚动正文，避免长备份名称影响布局。
