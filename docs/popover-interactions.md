# 菜单与浮动表单的一致定位

2026-11-09。所有应用菜单和浮动表单通过 `NotesPopover`、`NotesContentPopover` 与 `PopupPlacement.js` 采用同一套触发与定位规则。背景、材质、菜单行和键盘行为继续使用 Kos.Ui 公共组件。

## 规则

| 触发方式 | 位置 | 箭头 |
| --- | --- | --- |
| 鼠标右键 | 实际点击点；窗口边缘处收进 8px 安全区 | 无 |
| Menu 键／Shift+F10 | 当前行中点，沿用右键规则 | 无 |
| 点击操作按钮／更多按钮 | 按钮下方居中；空间不足时移到上方，边缘处收进安全区 | 指向按钮；无法准确指向时隐藏 |
| 正文斜杠建议 | 输入位置下方左对齐；空间不足时移到上方 | 无 |
| 后续菜单／编辑表单 | 关闭上一层，继承最初的按钮或右键位置 | 跟随最初的触发方式 |
| 确认、设置、结果报告 | 居中对话框 | 无 |

按钮表单不再在空间不足时跳到右侧或左侧。每次打开明确设置触发模式，避免同一个菜单上一次以右键打开后，下一次按钮打开还遗留无箭头或鼠标坐标。

## 已核对入口

- 笔记列表行、列表操作、标签和排序；最近删除行及列表操作。
- 顶层文件夹、子文件夹、窄窗口文件夹行：右键与键盘走上下文规则，行内更多按钮走按钮规则。
- 当前笔记操作、分享与导出、正文插入、表格操作、导入菜单。
- 正文右键、块操作按钮、更多编辑工具、斜杠建议。正文右键使用原始点击坐标，不再先夹到编辑区域并伪装成按钮锚点。
- 移动笔记、创建／重命名／移动文件夹、修改笔记标题、添加链接、窄窗口文件夹面板。
- 大纲、公式、代码、图片属性、附件管理、快捷键说明。
- 异步整理失败报告改为居中结果对话框，避免使用整块内容区作为浮动锚点。
- 设置／确认／导入／备份等独立对话框保留居中逻辑；选择器下拉由公共 LiquidSelect 负责贴着字段展开；提示由公共 KosToolTip 负责，均不混用操作菜单的入口。

## 本轮检查范围

完成全部应用菜单和浮动表单的源码入口核对。用户明确选择本轮只编译并打开，不运行测试或进行图形交互验证；边缘定位、连续切换和键盘操作尚未完成实际走查。
