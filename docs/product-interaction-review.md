# 笔记产品视角复查

2026-11-06。目标是让日常操作围绕记录、查找、归类、回看和输出内容；设置管理全局偏好与整个笔记空间。文件、原始路径和格式只在明确导入、导出、临时编辑外部文件时出现。

## 本轮发现与调整

| 问题 | 调整 |
| --- | --- |
| 设置里混有当前笔记的导出和打印 | 当前笔记菜单提供一个“分享与导出”二级入口，含 PDF、Markdown、HTML 和打印；设置数据只保留全库导出、导入与备份恢复 |
| 文件夹菜单导出排在新建前，并有绕过回收的删除空文件夹 | 新建、改名、移动排前；输出为次级操作；删除统一移到最近删除 |
| “搜索所有笔记”仍受当前分类限制 | 搜索暂切换全部笔记，关闭时返回原分类；显式切换分类会结束搜索并清空条件 |
| 搜索结果摘要可能截到 front matter 内部 | 摘要从正文开始，保留原始命中位置用于编辑器定位 |
| 普通空文件夹仍显示首次使用引导，切换分类可能保留别处的笔记 | 分类、收藏、随手记及无搜索结果各有明确空状态；切换先保存，不属于目标分类的当前笔记退出编辑区 |
| 关联页铺满文件路径与候选列表 | 默认展示“提到的内容”和“提到这篇笔记”，按标题和分类显示；按需展开标题搜索，候选最多展示八项 |
| 内部笔记、附件和网页都被当作原始出链展示 | 使用笔记标题、附件名称或网站名称；链接仍按原目标导航 |
| 从关联跳转可能打开一篇不在当前结果中的笔记 | 目标不在当前列表时回到全部笔记，保证目标在列表可见 |
| 外部文件打开后缺少明确的结束入口 | 外部身份栏提供“结束临时编辑”，等待保存后返回我的笔记，不将外部文件纳管 |
| 源码模式必须再进设置才能退出 | 编辑区直接显示“返回正文”，隐藏不可用的格式操作 |
| 笔记标题仍受文件名斜杠限制，可能与正文开头的标题脱节 | 标题允许斜杠，不更改笔记身份或分类；正文开头若为一级标题则同步更新，其他正文保留；分类名称仍保留必要规则 |
| 导出后自动打开文件管理器 | 留在应用内显示导出完成；仅点击“查看导出内容”才打开输出目录 |
| PDF／HTML 默认名称与文稿标题使用内部路径 | 使用笔记标题，输出文件名只在选择保存位置时处理系统不允许的字符 |
| 回收确认、辅助功能名称、草稿入口暴露内部路径 | 使用标题与分类层级；仅实际外部文件保留磁盘身份说明 |

## 合理保留的层级

- 新建、搜索、分类属于主界面；置顶、收藏、移动、修改标题、标签／关联／历史、创建副本及删除属于当前笔记。
- “分享与导出”是当前笔记的次级动作，不在顶部铺开多个格式按钮。
- 导入与整库导出、备份恢复仍在设置“数据”；模板、智能集合、批量标签、恢复草稿和外部 Markdown 仍在“高级”。
- 正文插入、表格、图片和公式继续在编辑现场；技术源码默认收起，退出方式直接可见。
- 虚拟分类允许层级，用“ › ”区分同名分类；它不代表用户必须管理磁盘路径。
