# 拖放归类与统一撤销

2026-11-06。参照 macOS 备忘录的拖动笔记归类、拖动文件夹形成子级的方式，沿用应用内分类和公共 Kos.Ui 视觉。

## 拖放

- 从列表拖动单篇笔记；拖动已选中的笔记时携带全部选中项，沿用当前 200 篇批量上限。
- 放到侧栏文件夹或随手记进行移动；“全部笔记”是聚合视图，不作为移动目标。文件夹拖到文件夹上成为子级，拖到“移到顶层”返回顶层。
- 有效目标以焦点色描边；折叠文件夹悬停 650ms 展开，靠近列表边缘自动滚动。拖动预览显示标题或篇数，Esc 取消。
- 无效目标不高亮、不执行：自己、后代、当前归属、同名文件夹冲突，以及忙碌期间。笔记同名冲突仍由原有事务处理并报告，不覆盖内容。
- 窄窗口拖到“文件夹”按钮上停留 500ms，展开目标面板；拖入具体分类后松手移动并收起面板。
- 拖放只传递应用内身份，不发布磁盘文件 URL，不移动导入源文件。原有移动菜单保留，作为键盘和辅助功能的替代入口。

## 撤销与重做

- 顶部按钮和 Ctrl+Z／Ctrl+Shift+Z 共用控制器入口，显示具体动作名；正文、源码和代码块键盘撤销也经过相同入口。表单输入框保留自身文字撤销。
- 新的正文输入优先使用编辑器原有细粒度历史；刚完成的整理操作优先使用整理历史。没有正文历史时可继续撤销整理操作。
- 整理历史覆盖笔记移动、批量移动、置顶、收藏、标签、标题和属性修改、创建副本、新建笔记，以及文件夹创建、改名、移动、删除和最近删除中的恢复。一次批量操作为一步，只记录成功的实际变化。
- 存储使用连接内临时触发器收集本次事务触及的笔记和文件夹；历史仅保留差异，移动中联动改写的链接也在同一步中回退。不会每次复制整个数据库。
- 回退验证变更列的当前值；保留无关列的后续编辑。有冲突、路径占用或可能留下失去父级的数据时整个回退事务回滚，提示未完成，原数据保留。
- 整理历史为本次应用会话所有，最多保留最近 50 步，并按正文大小裁剪旧记录。编辑或新整理操作会结束相应重做分支。
- 永久删除、整库恢复和导入是整理历史边界，不伪装成可撤销操作。偏好设置、导出、备份和外部文件管理不加入整理历史。

## 检查

只在 VM 隔离笔记空间人工操作，不运行测试套件。本机仅编译并打开最新版本供用户查看。

本轮实际操作结果：

- 拖动单篇笔记到 `DragReview`，有效目标高亮，释放后分类改变；撤销回到原分类。
- 选择三篇笔记后拖动，预览显示“3 篇笔记”；释放后全部归类，一步撤销分别回到原位置，快捷键重做后再次归入目标。
- 将带有三篇笔记的 `DragReview` 拖到 `Reference`，文件夹和笔记一起形成子级；撤销／重做保持内容与层级。随后拖到“移到顶层”成功返回根级。
- 父文件夹 `Personal` 拖到自己的 `Ideas` 子级没有目标描边，释放后不改变层级；拖到有效目标后按 Esc 取消，也没有移动。
- 540×600 窄窗口：悬停文件夹按钮展开目标，拖入 `Personal › Ideas` 成功，最终构建在落下后收起面板。
- 新建文件夹可撤销／重做；收藏可撤销／重做；删除笔记后从三篇变两篇，撤销恢复三篇，重做再次删除，再次撤销恢复。
- 正文输入检查文字，Ctrl+Z 撤回后字数从 30 回到 14，Ctrl+Shift+Z 重做恢复 30，再撤销回到 14；新输入结束整理重做分支。
- 新建笔记并输入后，第一次 Ctrl+Z 撤回文字，第二次撤回新建（四篇回到三篇）；Ctrl+Shift+Z 恢复新建笔记。修正了仅因自动保存时间变化导致无法撤回新建的问题。
- 修正拖动阈值造成的预览偏移；修正撤销移动时误选被联动改写的关联笔记；置顶／收藏回退不重新载入正文，保留正文历史。
- 本机与 VM 最终编译成功，最新本机版本已打开。VM 日志无 QML 加载错误、绑定循环、ReferenceError 或 TypeError；未运行测试套件。
