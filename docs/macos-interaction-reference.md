# macOS 备忘录交互参照

2026-11-06。产品交互以 macOS 备忘录为主要参照，并结合当前 SQLite 管理笔记、Markdown 导入、公共 Kos.Ui 组件及 Linux 键盘习惯实施。

## 统一规则

| 操作 | 入口与行为 |
| --- | --- |
| 新建、搜索、选择分类 | 主界面直接可达；所有分类中的正常笔记由“全部笔记”聚合 |
| 创建文件夹 | 侧栏底部创建顶层，具体行菜单创建子级；表单标明应用内归属 |
| 改名、移动、删除文件夹 | 具体行菜单；改名自动选中文字，移动排除自己、后代、当前父级和已有同名分类的位置 |
| 置顶、收藏、移动、标签、删除笔记 | 当前笔记或具体列表行；多选操作针对选中项，普通点击恢复单项编辑 |
| 排序 | 列表菜单，分类各自记忆；日期使用“最新在前／最早在前”，标题使用“标题升序／标题降序” |
| 输入表单 | 公共弹出层／对话框；明确提交和取消，Esc 可退出，不叠加个性化视觉样式 |
| 删除 | 先进入最近删除；永久删除继续确认，当前未实现统一撤销时保留软删除确认 |
| 导入、整库导出、备份恢复 | 设置“数据”，保留快捷导入；外部 Markdown 临时编辑放“高级” |
| 当前笔记输出 | 当前笔记的分享与导出菜单；不要求先进入全局设置 |

## 本轮落实

- 笔记移动默认显示当前位置，当前目标不可重复移动；批量移动跳过已经属于目标分类的笔记。
- 文件夹移动每次重新选择目标，避免沿用上次选择；排除同名冲突，显示被移动文件夹的层级。
- 文件夹改名自动聚焦并全选名称，标明父级；创建、改名和两种移动表单统一提供取消按钮。
- 统一“创建副本”命名，日期排序用明确的两个方向。

## 结合现状的边界

- 保留用户确定的列表右侧无箭头菜单，以及公共组件视觉；不照搬 macOS 原生菜单定位。
- 收藏、Markdown 源码、完整备份属于现有能力；保留在相应层级。
- 不增加尚未支持的 Apple 账户、协作、锁定、定时自动清理，也不暗示具备这些能力。AI 索引不在范围内。
- 拖放归类与统一撤销已补充，具体范围、边界与 VM 操作记录见 [拖放与撤销](drag-undo.md)。原有移动表单和最近删除仍作为替代入口。
