# 正文编辑（2026-11-05）

> 2026-11-06 存储方向更新：内部笔记改由 SQLite 管理，目录为虚拟分类；外部 Markdown 明确导入后才纳管。当前边界见 [管理式笔记说明](managed-notes.md)。本文旧文件仓库部分为历史说明，不再作为默认存储约定。

正文以内嵌 Milkdown / ProseMirror / remark 为编辑内核，Qt Quick / Kos.Ui 提供工具栏、块菜单、属性面板、大纲和文件对话框。内容继续保存在本地 Markdown 文件中。

## 已实现的操作

- `/` 插入菜单：中英文过滤、上下键选择、Enter 应用、Esc 取消；转换与文本输入共用撤销历史。
- 块操作：拖动、上下移动、多选、复制、内部粘贴、重复、删除、转换段落样式；Alt+Shift+上下键移动块。
- 大纲：标题跳转、折叠与展开；`[toc]` 实时目录；查找会展开匹配所在区域，折叠不改写源文件。
- 查找替换：Ctrl+F / Ctrl+H、大小写选项、上下一处、单次替换、全部替换、匹配计数及高亮；字数、词数、选区字数和阅读时间。
- 图片与附件：文件选择、粘贴图片、拖放、按内容去重落盘、图片替代文本与显示宽度；引用检查、回收与恢复。单个附件上限 32 MiB。
- 代码：语法高亮、语言选择、复制、离线 Mermaid 预览；预览不替换可编辑源码。
- 公式：KaTeX 行内/独立公式，LaTeX 编辑面板，双击编辑；支持 Markdown 加载/粘贴和行内公式输入规则。脚注使用上游 GFM schema。
- 表格：原有增删行列、对齐与导航之外，支持列宽、行列选择、数据行/列移动。表头保持首行。
- 英文拼写检查及右键建议；代码区关闭拼写检查。
- 独立 HTML、A4 PDF、PDF 打印预览；导出嵌入图片、图表和公式字体，展开折叠内容，去除编辑装饰。PDF 用独立离线页面排版，等待字体和图片就绪后原子写入。

## 存储和异步边界

未知 front matter 原样保留；只打开不编辑保留源文件写法；编辑后由上游 Markdown 序列化器规范化。图片/表格显示宽度为每篇笔记的应用偏好，不引入非标准 Markdown 宽度语法。附件写入 reserved `assets/`，回收前排空编辑区及待保存状态，磁盘仍有引用则拒绝回收，回收区可恢复。

异步导入以文档 epoch 和映射后的选区书签定位。输入法组合与上传完成前不允许切换/关闭越过 flush；上传完成后的插入也纳入该屏障。文档切换会关闭旧属性面板，过期回包不会写入新笔记。导出期间阻止切换和关闭，失败后恢复编辑。

所有脚本、字体和英文词典随包提供。正文图片通过 `nkasset:` scheme 读取，双重检查真实路径位于当前笔记库，仅暴露图片；网页无网络请求权限。PDF 排版使用独立 profile，只允许临时主文档和内嵌图片/字体请求。

手工回归必须指定当前打开的可丢弃笔记，通过 `NEXTNOTES_TEST_FILE`、`NEXTNOTES_CDP_URL`、`NEXTNOTES_TEST_REPORT` 配置；脚本会替换正文。构建 bundle、运行测试和 GUI 验证均只在 VM 执行。

## 当前边界

这是正文编辑功能范围，尚未实现 Notion 数据库、多人协作或双链知识图谱。未知 HTML 扩展继续保护为只读；双链补全、导航和反链已实现，见整理操作说明。拼写词典仅英文；公式面板支持块公式，不宣称完整覆盖所有手打块公式输入规则。约 2 MB、1.6 万段超长文已在 VM 专门测量，源码视图性能显著改善，正文模式打开与输入仍有停顿；大规模附件库的性能待验证。打印预览调用系统 PDF 查看器，不自动发送打印任务。

## Markdown 源码模式（2026-11-05）

“更多笔记操作”提供正文／Markdown 源码切换。源码显示完整文件文本，包括 front matter；普通输入、换行、缩进、纯文本粘贴、查找和中文输入沿用当前编辑会话。格式化正文工具在源码模式禁用。

两个模式使用同一个 ProseMirror 撤销历史，模式切换本身也是可撤销的一步；切换不清空已有历史。原文及不同 front matter 的上下文随文档历史保留，未编辑的往返不重新序列化文本。选区按文档相对位置近似映射。HTML 等未支持语法可以在源码中编辑保存，切回正文时如不能完整表达则留在源码并提示。

源码修改保留输入的末尾换行选择，同时沿用原文件 BOM／CRLF 编码约定。只读文件、外部冲突和恢复锁仍遵守原有存储保护。模式内输入法组合不提交 preedit；保存、切换和关闭继续通过现有 flush／revision 协议。

VM 回归脚本 `tests/SourceModeRegression.mjs` 使用显式指定的可丢弃笔记，覆盖完整源码往返、front matter、跨模式撤销／重做、不支持语法保存及 Chromium 中文组合输入。存储和会话测试补充了末尾换行、BOM／CRLF 与渲染器重连后更新 front matter 的保留。

本轮知识功能集成后，再次在 VM 运行正文、扩展编辑和源码模式回归。源码原文缓存现在忽略纯列宽变化，并关联模式切换后插件补齐尾段落的文档；文末为表格时，未编辑往返也保留原 Markdown 写法。源码模式的工具栏撤销／重做已启用，历史版本恢复复用这条撤销链。

## 长文打开优化（2026-11-05）

安全语法检查和正文转换共用一次 remark 解析；源码载入不做 Markdown 解析。文档语义摘要使用 WeakMap 按不可变文档缓存；光标和滚动上报仅发送状态，实际编辑及显式 flush 继续发送完整源码。去除原生侧未使用的整篇纯文本副本。没有修改界面样式或编辑模式选择。

这一轮同一 VM 的约 2 MB 长文从此前 13.41 秒降至两次实测 7.98／10.22 秒；当时构建编辑到保存约 2.48 秒，仍有约 2.38 秒的 Web 事件循环停顿。源码模式当时仍受超长文本排版影响，打开约 42.38 秒。此处为前一轮记录，后续结果见下节及整理说明。

VM 重新构建 bundle 与应用，并通过基础正文、扩展编辑、源码与双链回归，覆盖表格、公式、目录、脚注、附件、front matter、跨模式撤销重做、不支持语法保护、中文组合输入，以及双链转义、代码排除、补全与原生导航。新增真实 WebChannel 消息检查：光标变化不重复传全文，编辑必须发布最新源码。长文回归同时检查只打开不改写文件、编辑落盘和撤销后字节级恢复原文件。

## 源码可见区域渲染与长文编辑优化（2026-11-05）

`source-view.js` 为原有 `raw_source` 节点提供 CodeMirror 6 视图，只渲染可见行。输入增量同步回 ProseMirror，工具栏、键盘撤销与跨模式历史共用原会话；程序修改按文本差异更新源码视图。双向同步保留反向选区、中文组合输入、只读状态、滚动和查找高亮。源码不执行 Markdown 解析，完整内容仍参与保存与 flush。

性能采样发现 Milkdown 7.23.0 的序列化器为每个段落复制已经累积的段落数组。构建时用等价的追加操作替代，并预先收集 schema 候选表；运行时仍由原 serializer 生成 Markdown。`transformer-patch.mjs` 对源码结构做严格检查，升级后若结构改变会拒绝构建。`tests/TransformerRegression.mjs` 对原版与修正版比较嵌套格式、空白和 1.6 万段的完整语法树。

查找位置映射按文本片段保存，避免为长文每个字符分配索引。历史对照与恢复窗口关闭时不排版全文预览。启动及普通保存后的恢复刷新保留草稿锁和记录摘要，不读取所有提交版本正文；显式打开恢复中心仍加载并校验完整预览。窗口关闭后释放详情，窗口刚打开时到达的旧摘要不会覆盖详情。恢复记录、原文件和保留版本均不删除。

本次只处理渲染、数据同步和后台加载，没有进行视觉调优。VM 的性能结果 JSON 保留在 `output/source-performance-2026-11-05/`，运行日志与交互回归记录已清理；具体数字见整理说明。

最终验证：三组 CTest 通过，新增摘要不丢草稿锁、显式请求完整版本，以及窗口打开时旧摘要不能覆盖详情的回归。基础正文、扩展编辑、源码模式与双链四组 Web 回归通过。`tests/SourceViewportRegression.mjs` 在同一长文上验证实际输入、反向跨屏选区、系统剪贴板、换行缩进、键盘撤销、远处查找与编辑后高亮，并恢复原文件；必须预先打开 `NEXTNOTES_TEST_FILE` 指定的可丢弃笔记。原生窗口另验证了历史当前内容、恢复全文预览、连续关闭／重新打开，以及关闭时释放预览节点。

## 偶发正文黑屏的兼容处理（2026-11-05）

`EditorRenderLifecycle` 沿用 NkMail 阅读器的处理：只对当前 WebEngine 的渲染 delegate，解除窗口 `sceneGraphAboutToStop` 时提前释放纹理的连接，保留真正 `sceneGraphInvalidated` 与析构时的清理。窗口隐藏／最小化时可以暂停绘制而保留场景图，此时过早释放浏览器纹理可能留下黑色正文。适配器跟随 visual children 和 window 变化重新挂接，不轮询、不重新加载网页，编辑状态和撤销历史继续由原会话持有。

该适配器使用公开 QObject／Quick API，但识别了 Qt 私有 delegate 类名。它是应用侧兼容措施，不是 Qt 上游修复；参照 [Qt WebEngine 的连接与资源释放代码](https://github.com/qt/qtwebengine/blob/v6.11.2/src/core/render_widget_host_view_qt_delegate_item.cpp)。升级 Qt 后必须复核真实 WebEngine 测试，不能仅凭编译成功确认兼容。

开启 `NEXTNOTES_BUILD_TESTS` 后生成 `editor-render-test`，需在 VM 图形会话手动运行，未加入无显示器的默认 CTest。`tests/render/tst_surface.qml` 检查真实 delegate 挂接、实际渲染暂停、连续 6 次最小化／隐藏与恢复，以及未保存文字、反向选区、滚动、撤销重做、跨窗口重新挂接和文档替换。测试先等待窗口排版完成，再设置滚动位置。

本轮 VM Qt 6.10.2 的 Wayland／threaded OpenGL／EGL 生命周期回归通过；XWayland／OpenGL 也通过。实际应用的源码／正文往返、编辑落盘、中文组合输入和跨模式撤销重做回归通过，三组 CTest 通过。该轮日志已清理，未保留在仓库内。这些结果证明适配器和编辑状态回归正常，尚不能证明用户本机 Qt 6.12 偶发黑屏已彻底消失；本机不执行自动或图形验证，由用户正常使用观察。
